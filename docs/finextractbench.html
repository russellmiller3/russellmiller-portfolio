FinExtractBench: counting the wrong numbers

How often does AI write a wrong value when it copies a fund report into a spreadsheet? A blank is cheap: a person fills it. A wrong number looks right and stays.

The result

Two AIs made zero mistakes on 30 sealed reports. A control AI made one.

30fund reports, 781 pages
22facts asked per report
0mistakes: GPT-6.2 Sol, Gemini 4 Hydrogen
1mistake: Gemini 4 Carbon, the control

The answer key was written and sealed before any AI read a report. Each AI read each raw PDF once.

A mistake is a wrong value, a value for a fact the report does not state, or an event it does not support.

Zero in 30 still allows a mistake in about 1 report in 10 (95% confidence). This test shows big gaps between AIs, not small ones.

Why count mistakes

Facts found is the wrong score for this work.

Private-fund investors get one report per fund per quarter, each in its own layout. Someone copies the numbers and events into a spreadsheet by hand.

A blank costs a person a minute. A wrong value passes review and flows into decisions. So this test counts mistakes first.

Every score sits beside an all-blank answer sheet (0 mistakes, 0 facts), so no AI wins by saying nothing.

How it works

Choose, key, seal, run once, review blind.

  1. Choose: reports picked by rules written first; each PDF fingerprinted.
  2. Key: written by Claude (Anthropic's AI) to my rules; every answer carries its page and exact quote, checked by machine. Claude was not tested.
  3. Seal: keys, prompt and scorer fingerprinted before any AI ran.
  4. Run once: each AI reads each raw PDF one time.
  5. Review blind: every disagreement judged from the page, values unlabelled.

The blind review judged 57 disagreements: key right 19, AI right 22, both valid 16. The 32 key fixes apply to every AI.

The 22 facts

  • Fund, manager, period end, manager's outlook
  • Committed, paid-in, unfunded, net asset value, distributions, calls, borrowing
  • Net IRR, TVPI, DPI, number of companies
  • Events: investments, exits, add-ons, leadership, contracts, after period end

Only facts a report states are scored: 270 across the 30 reports.

Limits

What this test does not show

  • One AI wrote the key. Blind review fixed it where tested AIs disagreed; my own hand check against the pages is under way.
  • 30 reports. Zero bounds the rate only at about 1 in 10.
  • One run per AI. Run-to-run variation not measured.
  • Public, digital, English reports. At most 56 pages; one was a request for quotes, not a report.
  • One rule changed after launch. The control ran after key review; its check was not blind.
  • Few AIs sealed. Two finalists from an earlier 32-report round, plus one control.
